# Car Blueprint Explorer

An interactive 3D car explorer for kids, built with Three.js in a single HTML file. It shows a stylized grey 2024 Maruti Ignis.

- 💥 Explode Parts slider with floating labels
- 📐 Glowing wireframe blueprint / ✨ glossy paint toggle
- 🎨 8 paint colors
- 🔥 Rev Engine button: spinning wheels, vibration, engine sound
- Drag to orbit, scroll to zoom

Open `index.html` in a browser.
